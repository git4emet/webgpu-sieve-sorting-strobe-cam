# WebGPU Neon Simulation Requisite Skills

**Repository:** WebGPU Neon Demo.

## Requisite skills
- WebGPU compute pipeline construction.
- WGSL compute and render shader development.
- Fluid-inspired visual simulation.
- Ping-pong floating-point texture management.
- Pointer and mouse interaction.
- Real-time simulation parameter controls.
- Uniform-buffer updates without shader recompilation.
- Trail persistence and fade control.
- Brush size and color-intensity control.
- Swirl strength and hue animation.
- React and TypeScript interface integration.
- Browser/device WebGPU capability detection.
- Vite build and GitHub Pages deployment.

## Evidence boundary
The README documents the architecture and controls. It explicitly describes the simulation as fluid-inspired rather than a physically accurate fluid solver. Implementation source and runtime performance were not independently inspected or measured in this pass.
